# ИНСТРУКЦИЯ ДЛЯ АГЕНТА GEMINI (ANTIGRAVITY)

## Твоя задача:
Развернуть автономный ИИ-сервис новостного агрегатора и Telegram-бота на домашнем сервере (ноутбуке пользователя) и связать его с основным ПК (LM Studio).

Все файлы, скрипты и архитектура уже полностью написаны и находятся в репозитории:
`https://github.com/Mikaso-Nakamoto/-.-.git` (ветка `arena/4eea9db7-repo`).

---

## ШАГ 1: Подключение к Ноутбуку-серверу по SSH

Подключись к ноутбуку по SSH:
```bash
ssh <USER>@<IP_НОУТБУКА>
```
*(Если ты уже работаешь в терминале ноутбука, пропусти этот шаг).*

---

## ШАГ 2: Выполнение автоустановщика (В ОДНУ КОМАНДУ)

Выполни в терминале ноутбука следующую команду, которая автоматически скачает и запустит скрипт развертывания:

```bash
curl -sSL https://raw.githubusercontent.com/Mikaso-Nakamoto/-.-/arena/4eea9db7-repo/setup.sh | bash
```

Этот скрипт автоматически:
1. Проверит и при необходимости установит Docker и Docker Compose.
2. Склонирует репозиторий в папку `~/ai-news-hub` с нужной ветки `arena/4eea9db7-repo`.
3. Создаст все необходимые конфигурационные файлы (`.env`, `config/config.yaml`, `config/prompts.yaml`, `config/preferences.yaml`, `config/sources.yaml`).
4. Подготовит директорию для базы данных.

---

## ШАГ 3: Заполнение переменных окружения (.env)

Перейди в папку проекта:
```bash
cd ~/ai-news-hub
```

Открой файл `.env` для редактирования:
```bash
nano .env
```
Заполни значения:
1. `TELEGRAM_BOT_TOKEN` — токен бота пользователя (полученный от @BotFather).
2. `TELEGRAM_ADMIN_ID` — Telegram ID пользователя.
3. `LOCAL_QWEN_URL` — локальный адрес LM Studio на основном компьютере пользователя (по умолчанию: `http://192.168.1.150:1234/v1`).
4. (Опционально) `GROQ_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY` — ключи облачных сервисов для резервного переключения.

Сохрани файл (`Ctrl + O`, `Enter`, `Ctrl + X`).

---

## ШАГ 4: Запуск и проверка работы

Перезапусти контейнер с обновленными переменными окружения:
```bash
docker compose up -d --build
```

Проверь логи работы бота:
```bash
docker compose logs -f ai-agent
```

В логах должно появиться:
```text
[INFO] main: Планировщик запущен. Расписание дайджеста: 50 8 * * *
[INFO] main: 🚀 Автономный ИИ-хаб успешно запущен и готов к работе!
```

---

## ШАГ 5: Проверка связности с основным ПК (LM Studio)

Выполни прямо с ноутбука проверку доступности LM Studio:
```bash
curl http://<IP_ОСНОВНОГО_ПК>:1234/v1/models
```
- Если вернулся JSON со списком моделей — локальная нейросеть готова к работе!
- Если ошибка подключения — напомни пользователю включить в LM Studio галочку **"Serve on Local Network"** и нажать **"Start Server"**.

Сообщи пользователю в чат, что система успешно установлена и готова к тестированию в Telegram!
