### Аппаратное разделение:
1. **Старый ноутбук (24/7 Home Server):**
   - **Роль:** Master-координатор, веб-сервер, Telegram-бот, парсер источников, локальная БД (SQLite), планировщик задач (cron 08:50), шлюз VPN/Tailscale.
   - **Преимущества:** Минимальное энергопотребление, встроенный аккумулятор (работает как ИБП при скачках напряжения), тишина.
   - **Стек:** Docker Compose, Python 3.12 (asyncio), SQLite (WAL mode).

2. **Основной ПК (Workstation / Heavy Compute):**
   - **Конфигурация:** Intel Core i5-10400F, NVIDIA GeForce RTX 2060 Super (8 GB VRAM).
   - **Роль:** Локальный инференс-сервер для **Qwen 2.5 7B Instruct** через **LM Studio**.
   - **Оптимизация VRAM (8 GB):**
     - Модель Qwen 2.5 7B в квантовании `Q4_K_M` занимает ~4.7–5.2 ГБ VRAM вместе с KV-кэшем на 16k–32k токенов.
     - Доступен по локальной сети через порт `1234` (`http://<PC_LOCAL_IP>:1234/v1`).
   - **Режим доступности:** Если ПК выключен, находится в спящем режиме или занят играми/рендером, роутер автоматически перенаправляет запросы в облачные API.

3. **Облачный пул (Cloud Fallback & Scaling):**
   - **GroqCloud:** Молниеносная скорость генерации (300-500 токенов/сек) моделей Llama-3.3-70B-Versatile / Llama-3.1-8B. Идеально для быстрого утреннего дайджеста.
   - **Google AI Studio (Gemini 1.5 / 2.0 Flash):** Огромное окно контекста (до 1M токенов) и высокий бесплатный лимит (15 RPM). Подходит для одновременного скармливания сотен постов без дробления на чанки.
   - **OpenRouter:** Единый API для доступа к десяткам бесплатных моделей с суффиксом `:free` (Qwen 2.5 72B, DeepSeek, Mistral Nemo и др.).

## 2. Сбор новостей (Реалии 2026 года)

### Telegram-каналы:
1. **Бессерверный веб-скрапинг через Web-Preview (`t.me/s/<channel>`):**
   - Для всех публичных каналов не требуется сессия Telegram или API_ID/API_HASH.
   - Запросы идут по HTTPS через прокси или напрямую, парсинг HTML возвращает последние сообщения с датами, медиа и текстом.
   - Нет риска блокировки личного Telegram-аккаунта.
2. **Telethon / Pyrogram (опционально):**
   - Подключается через сессию пользователя для чтения закрытых/приватных каналов и чатов.

### RSS / Веб-источники:
- Парсинг стандартных RSS/Atom лент (Habr, TechCrunch, 3DNews, GitHub Releases, arXiv).
- Поддержка RSSHub (можно поднять локально в Docker) для конвертации любых страниц в RSS.

### Twitter / X:
- Официальный API закрыт за платный тариф.
- Решение 2026: Использование Nitter-инстансов / RSSHub bridges или агрегирующих Telegram-каналов, которые зеркалируют важные англоязычные твиты.

## 3. Интеллектуальный роутер LLM и отказоустойчивость

Роутер проверяет доступность локального ПК перед каждым обращением:
```python
# Псевдокод логики выбора провайдера:
if preferred_provider == "local":
    if healthcheck(pc_local_url):
        return call_qwen_local(prompt)
    else:
        logger.warning("Локальный ПК недоступен. Fallback на Groq/Gemini")
        return call_cloud_fallback(prompt)
```
Пользователь может в любой момент в Telegram через меню выбрать:
- **Auto (Локальный Qwen -> Groq -> Gemini -> OpenRouter)**
- **Only Local (Только мой ПК)**
- **Groq (Llama 3.3 70B)**
- **Google Gemini (Flash)**
- **OpenRouter (Free pool)**

## 5. Tailscale и сетевая связность

Для доступа к домашнему серверу вне дома и обхода операторских ограничений (белые списки / фильтрация):
1. **Tailscale Node на ноутбуке:**
   - Настраивается как `Exit Node` (`tailscale up --advertise-exit-node`).
   - Настраивается как `Subnet Router` для доступа ко всей домашней локальной сети (`192.168.1.0/24`).
2. **Клиент на телефоне:**
   - Подключение в 1 клик.
   - Трафик шифруется по WireGuard через порт 443 (DERP-реле при жестких ограничениях NAT/провайдера).
