# Мобильное приложение для Android (Google Discover + ИИ Чат)

В систему заложена поддержка двух вариантов мобильного клиента:

---

## Вариант 1: Установка прямо сейчас в 1 клик (PWA — Progressive Web App)

Это самый быстрый способ получить готовое приложение на телефоне без компиляции APK и регистрации в Google Play.

### Как это выглядит:
- **Вкладка 1 (Новости):** Лента карточек в стиле **Google Discover**. У каждой новости есть категория, выжимка сути, прямая ссылка и кнопки реакции 👍/👎, которые на лету обучают ваши рекомендации на сервере.
- **Вкладка 2 (ИИ Чат):** Полноценный интерфейс диалога с нейросетью с отображением задержки и активной модели.
- **Вкладка 3 (Сводка):** Текст последнего утреннего дайджеста.

### Как установить на телефон:
1. Подключите телефон к домашней сети по Wi-Fi (или через **Tailscale** из любой точки мира).
2. Откройте в Chrome на Android адрес:
   ```text
   http://<IP_НОУТБУКА>:8000/
   ```
   *(или адрес ноутбука в Tailscale, например `http://100.x.y.z:8000/`)*.
3. В меню Chrome нажмите **«Добавить на главный экран»** (или появится системная плашка *«Установить приложение AI News Hub»*).
4. На рабочем столе появится иконка приложения. Оно запускается на полный экран (без адресной строки браузера) и работает со скоростью нативного приложения!

## Вариант 2: Создание нативного Android-приложения (Kotlin / Flutter)

Если вы или Gemini захотите скомпилировать полноценный APK, сервер уже предоставляет готовый REST API:

### Эндпоинты сервера (`http://<IP_НОУТБУКА>:8000`):
1. **`GET /api/feed`** — лента свежих новостей для отображения карточек (возвращает JSON со списком новостей, ссылками, категориями).
2. **`POST /api/chat`** — отправка запроса в нейросеть (принимает `{"message": "текст"}`).
3. **`POST /api/feedback`** — отправка реакции (принимает `{"reaction": "like"|"dislike", "context": "заголовок"}`).
4. **`GET /api/digest/latest`** — получение последнего утреннего дайджеста.
5. **`GET /api/status`** — статус локального ПК и облачных моделей.
6. **Интерактивная документация:** доступна прямо в браузере по адресу `http://<IP_НОУТБУКА>:8000/docs` (Swagger UI).
