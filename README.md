# 🤖 AI News Hub — Автономный персональный ИИ-ассистент и новостной агрегатор (2026)

Распределенная самодостаточная система персонального мониторинга, фильтрации и анализа новостей с управлением через Telegram-бот.

Поддерживает гибридный инференс: локальная модель **Qwen 2.5 7B** на домашнем ПК с GPU (RTX 2060 Super 8GB) с автоматическим резервным переключением (failover) на сверхбыстрый **GroqCloud** (Llama 3.3 70B), **Google Gemini** (1.5/2.0 Flash с миллионным контекстом) и бесплатный пул **OpenRouter**.

## ⚡️ Ключевые возможности

1. **24/7 Автономность на слабом ноутбуке:**
   - Потребляет всего ~150 МБ оперативной памяти.
   - Батарея ноутбука выступает как бесплатный ИБП при перебоях с электричеством.
2. **Сбор новостей без риска бана Telegram-аккаунта:**
   - Сбор публичных каналов через официальный Web Preview (`t.me/s/`) без авторизации по номеру телефона.
   - Поддержка RSS/Atom лент (Habr, 3DNews, GitHub и др.).
3. **Умный роутер нейросетей с горячим переключением:**
   - Приоритет отдается локальной **Qwen 2.5 7B** на вашем ПК с RTX 2060 Super (квантование `Q4_K_M` занимает ~5 ГБ VRAM).
   - Если ПК выключен, спит или занят — мгновенный фоллбэк на облачные API без потери запроса.
   - Кнопки в боте для принудительного выбора любой модели.
4. **Утренняя сводка по расписанию (08:50):**
   - Автоматическая фильтрация мусора, стоп-слов, рекламы и скамов.
   - Выжимка по конкретным интересам пользователя (`preferences.yaml`).
5. **Готовность к удаленному доступу через Tailscale:**
   - Ноутбук может работать как Exit Node для телефона при белых списках 4G.

## 🚀 Быстрый старт

### 1. Настройка окружения на сервере (ноутбуке)
```bash
git clone https://github.com/Mikaso-Nakamoto/-.-.git
cd -.-

cp .env.example .env
cp config/config.example.yaml config/config.yaml
cp config/preferences.example.yaml config/preferences.yaml
cp config/sources.example.yaml config/sources.yaml
```

Заполните ваши ключи и токен в `.env`.

### 2. Запуск в Docker
```bash
docker compose up -d --build
```

### 3. Запуск локальной Qwen 2.5 на основном ПК (в LM Studio)
На основном ПК (где установлена RTX 2060 Super):
1. Откройте **LM Studio** и загрузите модель **Qwen 2.5 7B Instruct**.
2. В боковом меню перейдите во вкладку **Local Server** (значок `<->`).
3. Включите галочку **"Serve on Local Network"** (чтобы сервер слушал `0.0.0.0` вместо `127.0.0.1`).
4. Нажмите **"Start Server"** (по умолчанию порт `1234`).
5. Теперь ноутбук сможет отправлять запросы на `http://<IP_ПК>:1234/v1`.

## 📖 Команды в Telegram-боте
- `/start` — Главное меню и статус доступности локального ПК и облака.
- `/digest` — Сформировать и прислать дайджест прямо сейчас.
- `/model` — Меню смены активной нейросети (Auto / Local Qwen / Groq / Gemini / OpenRouter).
- `/status` — Подробный отчет о здоровье всех узлов.
- `/sources` — Список отслеживаемых каналов и лент.
